# Форма зворотного зв'язку

Адаптивна форма на HTML5 + Tailwind CSS + Vanilla JavaScript: клієнтська валідація, доступне модальне вікно успіху.

## Структура

```
feedback-form/
├── index.html                 # сторінка: форма + модальне вікно
├── README.md
└── assets/
    ├── css/style.css          # шрифт, scrollbar-gutter, prefers-reduced-motion
    ├── js/
    │   ├── validation.js      # валідація полів, стани, подія "feedback:valid"
    │   └── success-modal.js   # модальне вікно (<dialog>)
    ├── fonts/                 # порожньо: для локальних шрифтів
    ├── icons/                 # порожньо
    └── images/                # порожньо
```

## Запуск

Відкрийте `index.html` у браузері. Для коректної роботи з шляхами краще локальний сервер:

```bash
python3 -m http.server 8000
# потім http://localhost:8000
```

Tailwind підключено через CDN (`cdn.tailwindcss.com`), тому потрібен інтернет.

## Як це працює

1. Користувач заповнює форму. Поле перевіряється після `blur`, а далі оновлюється під час вводу. До першого контакту з полем помилок немає.
2. По `submit` перевіряються всі поля. Якщо є помилки, фокус іде на перше проблемне поле.
3. Якщо все валідно, `validation.js` викликає на формі подію `feedback:valid`.
4. `success-modal.js` слухає цю подію й відкриває `<dialog>`. Після закриття форма очищається (`form.reset()`), стани полів скидаються.

## Правила валідації

| Поле | `id` | Правило |
|---|---|---|
| Ім'я | `username` | мінімум 2 символи |
| Email | `email` | формат `name@domain.zone`, до 254 символів |
| Телефон | `phone` | строго `+380` і 9 цифр (`^\+380\d{9}$`) |
| Повідомлення | `message` | мінімум 10 символів |
| Згода | `agreement` | має бути відмічена |

Тексти помилок виводяться в елемент `<id>-error` під кожним полем.

## Що зробити перед запуском у production

- **Підключити відправку.** Зараз дані нікуди не надсилаються. У `validation.js` у функції `sendForm()` додайте `fetch`, а подію `feedback:valid` викликайте після успішної відповіді сервера.
- **Валідація на сервері.** Клієнтська перевірка легко обходиться. Додайте серверну, honeypot-поле та ліміт частоти запитів.
- **Сторінка політики.** Посилання `/privacy` у чекбоксі потрібно замінити на реальну сторінку.
- **Tailwind.** Замініть CDN на збірку через Tailwind CLI. Додайте `assets/js/*.js` у `content`, інакше класи станів `border-red-500` і `border-green-500` (вони є лише в JS) можуть не потрапити в CSS.
